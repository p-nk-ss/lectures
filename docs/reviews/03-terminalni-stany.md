## Внесені зміни (CHANGED-коментарі в MDX)

1. **15:1 → 15:2** для педіатричної СЛР двома медпрацівниками.
2. Енергія дефібриляції: «120–200 Дж» → «≥150 Дж біфазний / за інструкцією виробника; невідомо — максимум».
3. Додано положення ERC/RCUK 2025: телефонувати 112 негайно для будь-якої непритомної людини.
4. Розгорнуто контроль температури post-ROSC: запобігання гарячці замість рутинної гіпотермії.

### Що прибрано

Тут майже нічого не викидали за «зазубрювання»: частота компресій, доза адреналіну чи
інтервал його повторення — це рішення біля ліжка, а не дата. Прибрано лише ті початкові
питання, які нові кейси повторюють у тому самому формулюванні:

| Прибрано | Замінено кейсом |

| `n3` ґаспінґ | `nc1` — пацієнт із поодинокими вдихами в коридорі |
| `n7` коли дзвонити 112 | `nc2` |

| `n17` СЛР після просунутого повітроводу | `nc11` |

### Що додано понад лекцію

Два кейси виходять за межі тексту лекції й спираються на розділ ERC про реанімацію в
особливих обставинах:

- `dc49` — зупинка кровообігу у вагітної: зміщення матки вліво для звільнення нижньої порожнистої вени;
- `dc51` — продовження реанімації після тромболізису при підозрі на ТЕЛА.

Обидва питання позначені тут, бо перевіряють те, чого в лекції немає. Автору варто вирішити,
чи лишати їх у банку, чи додати відповідний абзац у лекцію.
