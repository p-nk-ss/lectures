# Спецификация: сайт лекций «Анестезіологія та інтенсивна терапія»

**Дата:** 2026-08-17
**Статус:** на ревью
**Домен:** `lectures.pankaz.dev`

## 1. Цель и контекст

Публичный сайт с актуализированными лекциями по дисциплине «Анестезіологія та інтенсивна терапія» (учебный план вуза, 2 содержательных модуля, 8 тем). Исходники — 7 презентаций .pptx автора и документ учебной программы .docx (в корне репозитория). Лекция по теме 5 («Гостра дихальна недостатність») отсутствует — создаётся с нуля.

**Аудитория:** смешанная — студенты-медсёстры и будущие врачи. Лекции пишутся на углублённом уровне; углублённые фрагменты оформляются сворачиваемыми блоками «для лікарів». Тесты — двух уровней сложности.

**Язык контента:** украинский. Язык UI: украинский.

**Роли:** Claude — извлечение, актуализация, черновики, визуал, код. Автор (Pankaz Jha) — медицинский эксперт, финальная проверка каждой лекции перед публикацией.

## 2. Формат и стек

- **Тип сайта:** статический, без логинов и БД. Прогресс студента — в `localStorage`.
- **Стек:** Astro + MDX (Content Collections), интерактивные островки на Preact (квиз, поиск-модалка, tooltip), Pagefind для поиска.
- **Хостинг:** Cloudflare Pages, автосборка из GitHub-репозитория, домен `lectures.pankaz.dev` через Cloudflare DNS (CNAME). Превью-деплои для веток/PR.

### Frontmatter лекции

```yaml
title: ...
slug: ...
module: 1 | 2
order: 1..8
description: ...
updatedAt: YYYY-MM-DD
sources: [ERC 2021, "наказ МОЗ №...", ...]
videos: [...]
status: draft | reviewed | published
```

**Гейт публикации:** в прод-сборку попадают только лекции со `status: published`. Статус меняется только после проверки автором. Это механическая защита от публикации неотревьюенных медицинских данных (дозировки, протоколы).

### Компоненты-блоки внутри MDX

- `<Important>` — критичная информация (красный callout);
- `<Dose>` — дозировки, визуально выделены (жёлтый, иконка);
- `<Algorithm>` — SVG-схема алгоритма;
- `<VideoEmbed>` — lite-embed YouTube (фасад, JS грузится по клику);
- `<ClinicalCase>` — клиническая задача;
- `<ForDoctors>` — сворачиваемый углублённый блок (медсёстры пропускают);
- `<T>` — термин глоссария с tooltip.

### Страницы

- **Главная** — 8 тем по 2 модулям, карточки с акцентными цветами тем, индикация прогресса (localStorage).
- **Лекция** — sticky-оглавление (сайдбар/выпадающее на мобильном), контент, в конце кнопка «Пройти тест по теме →».
- **/tests** — отдельный раздел: список 8 тем × 2 уровня (медсестра/врач), лучшие результаты из localStorage.
- **/glossary** — алфавитный список терминов с фильтром.

## 4. Pipeline актуализации (на каждую лекцию)

1. **Извлечение** — текст и изображения из .pptx (python-pptx / unzip). Старые изображения сохраняются для решения «оставить/заменить».
2. **Аудит** — сверка утверждений лекции с актуальными источниками: ERC Guidelines 2021 + обновления, AHA 2020/2025, действующие наказы/протоколы МОЗ Украины, современные учебники/обзоры (уровень UpToDate). Результат — таблица: «утверждение → актуально/устарело → текущая рекомендация → источник».
3. **Черновик** — новая MDX-лекция: структура прежней + обновлённые данные + новые разделы. Каждое медицинское изменение помечается в файле комментарием `<!-- CHANGED: было X, стало Y, источник Z -->`.
4. **Ревью-документ** — отдельный короткий MD со списком всех изменений и ссылками на источники + список недостающих фото («нужно фото X»), если открытых медиа не нашлось.
5. **Проверка автором** — правки напрямую в MDX или через Claude. Статус `draft → reviewed`.
6. **Публикация** — статус `published`, git push, автодеплой.

**Правило источников:** дозировки и протоколы берутся только из проверяемых опубликованных источников с ссылкой. Ничего «по памяти модели».

## 5. Визуал и медиа

- **SVG-схемы (создаёт Claude):** алгоритмы (BLS/ALS, DRABCDE, анафилаксия и т.п.), схемы патогенеза, шкалы (Глазго, Альговер, индекс Франка). Единый стиль, адаптивность, поддержка тёмной темы.
- **Открытые медиа (ищет Claude):** Wikimedia и аналоги — анатомия, ЭКГ-ритмы, оборудование. Лицензия в подписи, файлы оптимизируются в WebP.
- **YouTube (подбирает Claude, проверяет автор):** техники манипуляций; приоритет официальным каналам (ERC, клиники, мед. школы). Lite-embed.
- **Запрещено:** ИИ-генерация «медицинских иллюстраций» (риск анатомических ошибок). Только схемы и проверяемые источники.

## 6. Квизы

- **Раздел `/tests`, отдельно от лекций,** сгруппирован по темам. Из лекции — ссылка на её тест.
- **Объём:** 10–15 вопросов × 2 уровня на тему (медсестра — базовый; врач — углублённый, с клиническими задачами).
- **Формат JSON:** вопрос, 4–5 вариантов, правильный(е) ответ(ы), объяснение (почему + отсылка к разделу лекции), уровень.
- **Типы:** одиночный выбор, множественный выбор, клиническая виньетка (уровень «врач»).
- **UX:** по одному вопросу, мгновенная обратная связь с объяснением, итоговый экран, «повторить ошибочные», лёгкая геймификация (прогресс-бар, streak).
- **localStorage:** лучший результат по каждой паре тема×уровень.
- Вопросы генерирует Claude из актуализированного контента; проверяются автором вместе с лекцией.

## 7. UI/дизайн

- **Направление:** современный эдтех (вектор Osmosis/Duolingo): яркая контролируемая палитра, у каждой из 8 тем свой акцентный цвет.
- **Mobile-first:** основное чтение с телефонов. Крупный кегль, межстрочный интервал ~1.7, ограниченная ширина колонки.
- **Шрифты:** Inter/Manrope (кириллица) + системный fallback.
- **Темы:** светлая/тёмная, переключатель, по умолчанию системная.
- При реализации применяются скилы frontend-design, design-taste-frontend, ui-ux-pro-max (палитры, шрифтовые пары, UX-гайды).

## 8. Поиск и глоссарий

- **Pagefind:** индексация на этапе сборки, полнотекстовый поиск по лекциям, украинский язык, модалка по `Ctrl+K`/иконке. Работает на чистой статике.
- **Глоссарий:** коллекция (термин, определение, синонимы). Страница `/glossary` + tooltip-компонент `<T>` в тексте лекций.

## 9. Порядок работ

1. **Каркас:** Astro-проект, дизайн-система, layout'ы, главная, шаблон лекции, квиз-движок, поиск, глоссарий-механика. Пилотная лекция — **Тема 3 «Термінальні стани»** (обкатка всего pipeline: алгоритмы СЛР, видео, схемы).
2. **Деплой** каркаса с пилотом на `lectures.pankaz.dev` (GitHub → Cloudflare Pages).
3. **Остальные лекции поочерёдно** (1, 2, 4, 6, 7, 8) по pipeline из раздела 4 + квизы; глоссарий пополняется по ходу.
4. **Тема 5** — с нуля по учебной программе + guidelines, ревью как обычно.

## 10. Вне рамок (YAGNI)

- Логины, серверная БД, серверный прогресс.
- Страница «О преподавателе», формы обратной связи.
- PDF/печатная версия.
- ИИ-генерация медицинских иллюстраций.

Позже добавить можно — архитектура не блокирует (Cloudflare Workers рядом при необходимости).
