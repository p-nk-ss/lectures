# Лекції: Анестезіологія та інтенсивна терапія

Статичний сайт лекцій для `lectures.pankaz.dev`: актуалізовані лекції за сучасними протоколами (ERC 2021/2025, AHA 2020/2025, накази МОЗ України) + тести для самоконтролю, глосарій і пошук.

## Структура

- `site/` — Astro-проєкт (Preact-островки, MDX, Pagefind, Vitest).
- `site/scripts/build-quiz-sprites.mjs` — збирає графіку сцени тестів із вихідників у `images/tests/`; редагувати сцену треба через скрипт, а не правити PNG руками.
- `lectures/` — вихідні pptx-презентації.
- `content-src/` — сирий текст, витягнутий із pptx.
- `docs/superpowers/` — дизайн-спека і план реалізації.
- `docs/reviews/` — ревʼю-документи лекцій (аудит актуальності, чеклист автора).

Стан лекцій: 01 «Поняття про анестезіологію та реаніматологію», 02 «Інгаляційний та неінгаляційний наркоз», 03 «Термінальні стани», 04 «Гостра серцево-судинна недостатність» і 05 «Гостра дихальна недостатність» — чернетки, чекають на авторське ревʼю. Решта тем ще не написані.

## Сторінки

- Головна — каталог тем із прогресом читання.
- Лекція — режим презентації: кожен розділ на окремому екрані, HUD із прогресом, навігація з клавіатури.
- Тести — квізи двох рівнів (медсестра, лікар) із збереженням найкращого результату. Проходження зроблено як діалог у піксельній грі: лікарка Вірджинія ставить питання в комікс-хмарі, на весь тест 10 хвилин і три життя.
- Глосарій — терміни з підказками, які спливають прямо в тексті лекцій.
- Відео — усі відеоматеріали лекцій із посиланнями на розділи, де вони трапляються.

## Розробка

Node 22.12+ (див. `engines` у `site/package.json`).

```bash
cd site
npm install
npm run dev      # dev-сервер (чернетки видно)
npm test         # vitest
npm run check    # astro check
npm run build    # прод-збірка + індекс Pagefind
```

## Публікація лекцій

1. Лекція створюється зі `status: draft` — видна в dev і в preview-деплоях (`SHOW_DRAFTS=1`), у прод не потрапляє.
2. Аудит джерел і зміни фіксуються в `docs/reviews/<slug>.md`.
3. Автор перевіряє чернетку та чеклист ревʼю-документа.
4. `status: published` → commit → merge в `main` → автодеплой у прод.

## Деплой

Cloudflare Pages: Root directory — `site`, Build command — `npm run build`, Output — `dist`. Для Preview-оточення встановлено `SHOW_DRAFTS=1`. Прод-домен — `lectures.pankaz.dev`.
